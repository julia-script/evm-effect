Recursive Length Prefix encoding, the serialisation format used for Ethereum
transactions, headers and trie nodes.

```bash
npm add @evm-effect/rlp effect
```

```ts
import { decode, encode } from "@evm-effect/rlp";
import { Bytes } from "@evm-effect/ethereum-types";

const encoded = encode(["cat", "dog"]);
const decoded = decode(encoded);
```

`encode` accepts the `Extended` input type — byte strings, addresses, unsigned
integers, booleans, strings and nested sequences. Decoding failures surface as
`RlpDecodeError`, an Effect data type carrying the path at which decoding
failed, so they can be handled without `try`/`catch`.
