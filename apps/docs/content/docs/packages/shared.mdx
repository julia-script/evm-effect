---
title: "@evm-effect/shared"
description: Internal utilities shared across the evm-effect packages.
---

Hash maps and hash sets tuned for the EVM's key types, tracing helpers and
stringification utilities. It is published so that dependents such as
`@evm-effect/evm` resolve from npm — most applications do not need to depend on
it directly.

```bash
npm add @evm-effect/shared effect
```
