`evm-effect` is an Ethereum Virtual Machine implementation written in TypeScript
using [Effect](https://effect.website/). It is designed for developer tooling
that needs deep introspection into execution — debuggers, tracers, profilers and
testing frameworks — where structured concurrency, typed errors and built-in
tracing make every step of a transaction observable.

## Packages

| Package | Description |
| ------- | ----------- |
| [`@evm-effect/evm`](/docs/packages/evm) | Interpreter, block and transaction processing, state, precompiles, tracing |
| [`@evm-effect/solc`](/docs/packages/solc) | Compile Solidity through Effect, on Node or in a browser worker |
| [`@evm-effect/ethereum-types`](/docs/packages/ethereum-types) | Ethereum primitives: `Address`, `Bytes`, `Uint`, `U256`, … |
| [`@evm-effect/crypto`](/docs/packages/crypto) | keccak256, sha256, secp256k1 signing, ethash |
| [`@evm-effect/rlp`](/docs/packages/rlp) | RLP encoding and decoding |
| [`@evm-effect/rpc`](/docs/packages/rpc) | Effect schemas for the Ethereum JSON-RPC surface |
| [`@evm-effect/shared`](/docs/packages/shared) | Shared utilities used across the packages |
